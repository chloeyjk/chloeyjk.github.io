Multi-trial Reliability

Agents are stochastic, so a single run per task hides a lot. pass@k, pass^k, and repeated measures.

Key idea

Run each task n times and record c successes. pass@k = 1 − C(n−c, k)/C(n, k) estimates the chance at least one of k tries succeeds; pass^k = C(c, k)/C(n, k) estimates the chance all k succeed. Repeated trials form a hierarchical design with trials nested in tasks, so variance comes from both levels.
