Comparing Agents

Is agent A actually better than agent B? Paired designs, preference models, and cost.

Key idea

When two agents run on the same tasks, analyze the per-task differences dᵢ = aᵢ − bᵢ rather than two separate means. Because task difficulty affects both agents, the differences have much lower variance, so the same data gives a tighter interval for A − B.
