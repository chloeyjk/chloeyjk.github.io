An illustrated study

Is 62% better than 58%?

A leaderboard shows Agent A at 62% and Agent B at 58% on a 100-task benchmark. This study walks through what a biostatistician would ask before believing the gap.

1. A score is an estimate

The 100 tasks are a sample of the tasks we actually care about. With pass/fail tasks at 62%, the per-task standard deviation is √(0.62 × 0.38) ≈ 0.485, so the standard error is 0.485 / √100 ≈ 4.9 points. The 95% interval for Agent A is 52.5% to 71.5%, a 19-point-wide range around a single number on a leaderboard.

2. Compare the difference, not two intervals

If we treat the two scores as independent, the difference is 4 ± 13.6 points. But both agents ran on the same tasks, and hard tasks are hard for both. That shared difficulty is a positive correlation between their results. Assume it's 0.6, which is realistic for agents built on similar models.

The paired analysis works with per-task differences. Their standard deviation is √(σ²ₐ + σ²ᵦ − 2ρσₐσᵦ) ≈ 0.438, so the difference becomes 4 ± 8.6 points. That's much tighter, but it still includes zero.

3. How many tasks would it take?

To detect a true 4-point gap with 80% power at the 5% level, a paired design needs about 941 tasks; an unpaired one needs about 2,351. Most agent benchmarks have a few hundred tasks. Card et al. (2020) found the same underpowering in NLP.

4. Three things that change the answer

  • Clustering. If tasks come in groups (ten tasks from one repository), they aren't 100 independent draws. Clustered standard errors are wider. See Uncertainty.
  • Repeated trials. Agents are stochastic. Running each task several times shrinks the within-task noise, and shows whether an agent is reliably right (pass^k) or occasionally right (pass@k). See Multi-trial Reliability.
  • Judge error. If an LLM judge scores the tasks, its mistakes are measurement error, and they can be biased toward one agent. See LLM Judges.
