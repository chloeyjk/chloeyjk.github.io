Harness Playbook

How this hub is built and kept current: what the agents do, what I do, and the rules that keep the catalog trustworthy.

The loop

  1. Collect. Weekly, an agent (Claude Code) searches for new work on agent evaluation and statistical methods, using the weekly scan template. It returns candidates only; it doesn't edit the site.
  2. Verify. Every candidate is checked against its primary source: arXiv abstract page, ACL Anthology, or the publisher. Title, authors, and date must match exactly. Anything the agent can't verify is dropped.
  3. Triage. I read the abstract, and the methods section for anything that sounds statistical, then decide whether it earns a place. The summary is rewritten in my words, stating what the paper actually does.
  4. Add. Append the entry to research/catalog.json. The topics field places it on the Methods pages. Never delete or silently rewrite an entry; add a correction instead.
  5. Publish. Run the tests, commit, and push. GitHub Pages redeploys in about a minute.

Rules

  • The source is the authority. Summaries point to papers; they don't replace them.
  • No unverified citations. Language models invent plausible-looking references. A citation is only added after its source page has been opened.
  • Append-only. The catalog is a research record. Its history, in git, shows how my reading evolved.
  • Public data only. Nothing from coursework, unpublished lab work, or collaborators' drafts.
