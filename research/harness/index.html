Harness Playbook

How this hub is built and kept current: what the agents do, what I do, and the rules that keep the catalog trustworthy.

The loop

  1. Scan (weekly, automated). A scheduled Claude Code agent runs in the cloud once a week. It follows .agent/weekly-scan.md: search arXiv and lab blogs for the past 7 days, and keep only work where the statistical method matters.
  2. Verify. The agent opens every candidate's source page and copies the title and date from it. Anything it can't verify is dropped, never cited from memory.
  3. Propose. It adds entries and progress notes to research/catalog.json, writes a weekly brief, runs the validator and tests, and opens a pull request. It never pushes to main.
  4. Review. I read the pull request: the sources, the summaries, and the "considered, not added" list. I edit anything wrong, then merge.
  5. Publish. Merging deploys the site through GitHub Pages within about a minute.

Rules

  • The source is the authority. Summaries point to papers; they don't replace them.
  • No unverified citations. Language models invent plausible-looking references. A citation is only added after its source page has been opened.
  • Append-only. The catalog is a research record. Corrections and follow-ups go in an entry's progress notes; nothing is deleted.
  • Public data only. Nothing from coursework, unpublished lab work, or collaborators' drafts.
